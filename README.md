## Browse and download

- Use the [website](https://qminmu.github.io/marginalia/) to select a course, filter by category, and search filenames.
- Open a PDF in the browser or download an individual file.
- Browse the original folders under [`courses/`](courses/), or download the entire repository with **Code → Download ZIP**.

## Organization

```text
courses/
└── 电路测试实验/
    ├── 实验讲义/
    ├── 课件/
    ├── 教材与报告/
    ├── 历年试题与解析/
    └── 复习总结/
```

Each course has its own folder and file index. Additional courses can be added as sibling folders. The website reads `catalog.json`, which records filenames, categories, file sizes, page counts, and SHA-256 checksums. When adding materials, update the course index and catalog together.
